# Future Enhancements

Chat features deferred from the initial build. The original deferral list below has all since shipped; see the [`docs/superpowers/plans/`](docs/superpowers/plans/) phase plans and the README feature list for what landed.

The live roadmap now lives in the YouTrack project (LC-* issues), not in this file.

## Shipped (was deferred from the initial build)

- **Private/invite-only rooms** - rooms that require an invitation or membership to view and join
- **File/image uploads** - attach files and images to messages, with configurable size limits
- **Message editing** - edit your own messages after sending, with an edit-history drawer
- **Reactions/emoji** - emoji reactions, including custom emoji
- **Typing indicators** - show when other users are typing in a room
- **Read receipts** - track and display which messages have been read by participants
- **Message search** - full-text search across messages the user has access to
