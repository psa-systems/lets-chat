# Features

Everything here is current shipping behavior. Features that need operator configuration call that out.

- [Messaging](messaging.md): rooms, direct messages, reactions, search, polls, slash commands, mentions.
- [Calls](calls.md): 1:1 audio and video, huddles, stage mode, screen share, in-call chat, call transcription.
- [Spaces](spaces.md): enclaves, user groups, wikis, categories, presence and status.
- [Search](search.md): full-text search of your rooms, optional semantic search and "Find related".
- [Transcription agent](transcription-agent.md): optional server-side agent that writes live captions and post-call transcripts into a call room.

Not every feature is on by default. A feature that needs operator configuration says so at the top of its page.
