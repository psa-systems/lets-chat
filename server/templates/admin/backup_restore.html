Create backup

Downloads a single .zip with consistent SQLite snapshots (via VACUUM INTO) of all three databases plus the uploads/ and avatars/ trees. Each entry is sha256'd into a manifest.json so a later restore can verify integrity. The server keeps serving while the snapshot runs. Large deployments may take a minute or two; the response begins streaming as soon as the archive finishes building on disk.

Restore from archive

Upload a previously-downloaded backup. The server validates the manifest + per-file sha256, refuses archives built on a different lets-chat version, then stages the contents in a sibling directory. A restart finalizes the swap.
