{# LC-740: the one file picker. Every user-facing file input in the app renders through this partial, so all of them look the same, echo the chosen filename, and reject a wrong type or an oversized file inline before submit (see assets/file_picker.js, one delegated handler keyed off `data-lc-file-picker`). The native input stays `sr-only` so the browser's "no file chosen" chrome never renders next to our own echo. Callers bind these with `{% let %}` before the include: `input_id`, `name`, `accept`, `max_bytes`, `choose_label`, `no_file_label`, `err_type`, `err_size`, `required`. `max_bytes` MUST match the limit the handler behind `name` enforces. Any help text goes in the caller, after the include, so the error slot sits directly under the control. #}
